# `src/shared/design` Architecture

Design tokens shared across the app.

## Files

- `colors.ts`: color palette.
- `spacing.ts`: spacing scale.
- `typography.ts`: text style scale.
- `radius.ts`: border radius scale.
- `shadows.ts`: shadow/elevation tokens.
- `tokens.ts`: aggregate token exports.

Use these tokens instead of hard-coded styles when building feature UI.
