# Android Instrumentation Tests

## Purpose

`BackgroundSynthesisWorkerInstrumentedTest` starts the production WorkManager worker in a cold React Native process, runs the registered Headless JS queue task with a verified local Gemma model, and checks that an Inbox source is removed only after its categorized topic copy is durable. Run it separately from Detox with the debug AndroidTest APK and a 6 GB API 30+ emulator that has the verified model and manifest installed under app-private `files/models/`. A release variant is also buildable, but AndroidX Test instrumentation is incompatible with the app's release-shrunk Kotlin runtime; keep this check on the debug variant and verify the signed release by install/launch smoke.

`ContextEngineAndroidTestRunner` applies a `DetoxTest` class filter only when Detox supplies `detoxServer` and no explicit `class` argument. This prevents app instrumentation tests from starting alongside UI journeys and mutating their fixtures. Regular native runs accept AndroidJUnitRunner's `class` filter, for example `adb shell am instrument -w -e class com.meharaj.contextengine.QuickTextCaptureInstrumentedTest#captureWidgetFitsItsMinimumAndExpandedWidths com.meharaj.contextengine.e2e.test/com.meharaj.contextengine.ContextEngineAndroidTestRunner`.

For 2026-11-01 API 36 QA, run filtered native classes against the isolated `.e2e` app/test APK pair. `QuickTextCaptureInstrumentedTest` passed 6/6 after granting the test app `POST_NOTIFICATIONS`; `AutomaticReminderInstrumentedTest` passed 4/4. The real background synthesis worker test skipped because the verified Gemma model is absent. `HeadsetMediaButtonControllerInstrumentedTest` currently fails when explicitly instantiated because `HeadsetMediaButtonReceiver` is not registered in the manifest; headset triggers are disabled in v1 and are not a release gate. The notification-clear assertion waits for Android's active-notification state to settle after cancellation.

`QuickTextCaptureInstrumentedTest` uses isolated app-cache outbox fixtures to verify malformed-record and invalid-timestamp retention, later valid captures, and duplicate-save identity. System-notification checks verify distinct reply PendingIntents, stale success suppression, separately retained stale failures, and current-result updates. It needs notification access and no model; validated on the connected API 30 emulator.

Its widget layout tests also cover compact/expanded widths, taller launcher slots, light/dark resources, larger text, a long recording counter, and accessible icon actions at 2.0 text scale. These two methods pass on API 36 without clearing app data. Passing `-e captureWidgetPreviews true` saves optional native layout PNGs to the target app's external-files directory; the normal test run writes no previews.

`WidgetVoiceCaptureInstrumentedTest#backgroundCaptureFinalizesDurableAudioAndQueuesSynthesis` starts the production microphone service from the native capture surface, moves its Activity to the background, stops recording, then verifies a valid retained WAV, its recovery descriptor or Inbox note, and the durable WorkManager synthesis request. Run on the isolated `.e2e` app with an API 36 emulator; the test adds only uniquely named voice data and never clears app storage.

On 2026-11-02, API 36 instrumentation passed `WidgetVoiceCaptureInstrumentedTest#backgroundCaptureFinalizesDurableAudioAndQueuesSynthesis` (1/1), `QuickTextCaptureInstrumentedTest#synthesisModelDownloadContinuesWithoutAnActiveApp` (1/1), `QuickTextCaptureInstrumentedTest#widgetWriteCaptureRunsReminderAndSynthesisInBackground` (1/1), and `BackgroundSynthesisWorkerInstrumentedTest#coldStartedWorkerRecoversWidgetVoiceTranscribesAndFilesIt` (1/1) on the isolated `.e2e` app. The model download continued with the launcher active and no app Activity, displayed its foreground notification, and passed the pinned 584,417,280-byte size and SHA-256 checks. Widget text was filed through background Whisper/Gemma processing; a retained widget-format WAV was transcribed and filed by the cold-started worker. Android Detox also passed 8/8 fixture-free starter journeys and Android UX review 1/1. Targeted real-Gemma UI filing passed 1/1 with the verified model. Physical launcher-microphone speech transcription remains unverified; the voice worker check uses a retained speech fixture.

`QuickTextCaptureInstrumentedTest#widgetWriteCaptureRunsReminderAndSynthesisInBackground` exercises the widget's native Write activity, background Whisper download, WorkManager processing, and model-backed filing on API 36. `#synthesisModelDownloadContinuesWithoutAnActiveApp` removes only the isolated test app's Gemma fixture, grants notification access to the test app when Android 13+ requires it, enqueues the production model-download worker with no target Activity active, then verifies its foreground notification, final size, and pinned SHA-256. The latter needs network access and may take several minutes. `BackgroundSynthesisWorkerInstrumentedTest#coldStartedWorkerRecoversWidgetVoiceTranscribesAndFilesIt` uses the verified model and retained JFK speech fixture to check background transcription, synthesis, durable topic filing, Inbox removal, and audio cleanup.

`QuickTextCaptureInstrumentedTest#whisperDownloadContinuesAfterTheAppIsBackgrounded` removes only the isolated test app's Whisper model and unique download work, launches through Metro, waits for a non-empty download chunk, backgrounds MainActivity, and verifies the foreground notification, 32,166,155-byte model, pinned SHA-256, and Headless JS task completion. Waiting for active bytes avoids backgrounding before the React Native app has started its download. It passed 1/1 on API 36 on 2026-11-02. The debug APK needs Metro with ADB reverse on port 8081 and network access.
