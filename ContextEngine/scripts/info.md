# `scripts` Architecture

Project scripts directory.

## Active Scripts

- `validate-current-phase.js`: reads `implementation/status.json.currentPhase`, loads the matching phase from `implementation/phases.json`, and runs that phase's `validation` commands in order. Safe for local and CI use when the listed phase commands are supported by the environment.
- `real-device-qa.js`: runs repeatable real iOS device QA through a live WebDriverAgent endpoint, captures XML evidence snapshots, and writes a behavior summary JSON under `artifacts/real-device-qa/<timestamp>/`. Local/manual only (requires connected unlocked iPhone + WDA).
- `build-ios-release.sh`: creates a generic-device Release archive at `build/ContextEngine.xcarchive` with automatic provisioning updates enabled. Local/manual only because it requires Xcode and an Apple signing identity.
- `with-release-env.sh`: loads the git-ignored `.env.release.local` file before release/preflight commands without printing secrets.
- `import-apple-distribution.sh`: imports the configured Apple Distribution P12 into the login Keychain and installs its App Store provisioning profile under Xcode's user profile directory.
- `apply-release-metadata.js`: local/manual helper that stamps `docs/privacy-policy.md` and `docs/store-submission-package.md` from the values stored in `.env.release.local`.
- `release-preflight.js`: local/manual, read-only store-release check for disk, Xcode, signing inputs, pinned Android dependencies, API/version metadata, merged-permission intent, backup boundaries, iOS privacy/capability metadata, privacy and store placeholders, store graphics/screenshots, and product naming. It reports all blockers and exits non-zero until every check passes.
- `fix-whisper-rn-codegen.js`: post-install compatibility patch for the installed Whisper React Native codegen metadata. Runs automatically after `npm install`.
- `strip-unused-rnfs-disk-api.js`: removes the unused iOS `react-native-fs` disk-capacity export after install so the release binary does not contain an undeclared required-reason API. It fails loudly if the dependency source layout changes and needs a fresh privacy audit.
- `check-android-16k.js`: verifies release-APK ZIP alignment and every packaged arm64 ELF `LOAD` segment against Google Play's 16 KB page-size requirement. Run `npm run android:check-16k` after assembling the final release APK; safe for CI when Android SDK 36 and the pinned NDK are available.
- Store screenshots are generated by the guarded Detox journey in `e2e/store-screenshots.test.js` through `npm run store:screenshots:ios`, `npm run store:screenshots:ios:ipad`, and `npm run store:screenshots:android`; it is local/macOS-only because it uses Simulator, ADB, `sips`, and `ffmpeg`.
- `ensure-ios-store-simulator.js`: local/macOS-only idempotent setup used by both iOS screenshot commands; it reuses an available matching simulator or creates the required iPhone 16 Pro Max / 13-inch iPad on the newest installed iOS runtime.

Before adding scripts, document their purpose, required environment, and whether they are safe to run in CI or only intended for local/manual use.
