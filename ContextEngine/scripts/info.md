# `scripts` Architecture

Project scripts directory.

## Active Scripts

- `patch-rn-audio-pcm-stream.js`: keeps Android PCM capture/stop/error handling reliable and makes iOS activate its microphone audio session, await AudioQueue start/stop, and reject native startup errors. It runs during post-install, changes Android behavior only through its existing gated capture path, and fails loudly if either dependency source layout changes.
- `validate-current-phase.js`: reads `implementation/status.json.currentPhase`, loads the matching phase from `implementation/phases.json`, and runs that phase's `validation` commands in order. Safe for local and CI use when the listed phase commands are supported by the environment.
- `real-device-qa.js`: runs repeatable real iOS device QA through a live WebDriverAgent endpoint, captures XML evidence snapshots, and writes a behavior summary JSON under `artifacts/real-device-qa/<timestamp>/`. Local/manual only (requires connected unlocked iPhone + WDA).
- `build-ios-release.sh`: creates a generic-device Release archive at `build/ContextEngine.xcarchive` with automatic provisioning updates enabled. Local/manual only because it requires Xcode and an Apple signing identity.
- `with-release-env.sh`: loads the git-ignored `.env.release.local` file before release/preflight commands without printing secrets.
- `import-apple-distribution.sh`: imports the configured Apple Distribution P12 into the login Keychain and installs its App Store provisioning profile under Xcode's user profile directory.
- `apply-release-metadata.js`: local/manual helper that stamps `docs/privacy-policy.md` and `docs/store-submission-package.md` from the values stored in `.env.release.local`.
- `release-preflight.js`: local/manual, read-only store-release check. Default combined mode checks the least-free volume holding the iOS or Android release outputs, Xcode/Apple signing, Play signing, Android package metadata and permissions, iOS privacy/capability metadata, privacy/store placeholders, graphics, screenshots, and product names. `--platform=android` skips iOS-only checks while retaining shared and Play gates. Android checks include pinned dependencies, exact 1.0.6/7 APK/AAB package/API/version parity, upload-certificate signature parity, and 16 KB ELF/ZIP alignment, on-demand voice scope, backup boundaries, and two ready-to-use Play screenshots verified with built-in macOS Vision OCR. It requires a built release manifest before claiming merged permissions are verified. Set `CONTEXTENGINE_BUNDLETOOL_JAR` to an official bundletool JAR for AAB manifest and `PAGE_ALIGNMENT_16K` inspection; missing tools fail the gate. Both artifacts must embed the current deterministic source fingerprint, so stale binaries fail even when timestamps are recent.
- `release-provenance.js`: hashes an explicit app/Android/build-input allowlist, including uncommitted source and bundled assets, into a generated `release-provenance.json` asset. Signing keys, local environment files, captures and generated outputs are outside the allowlist; the asset stores only schema/algorithm/hash/count, without source content or timestamps. AGP generates it per release variant before assets merge. Safe for CI; release sources must remain stable throughout build and preflight.
- `release-artifact-checks.js`: shared pure manifest parsing and release permission/metadata contract used by preflight and the self-check.
- `release-gates.selfcheck.js`: run `node scripts/release-gates.selfcheck.js` for temporary-fixture checks of deterministic provenance, stale-source rejection, Android metadata/permissions and production-package reset refusal. Safe for CI; does not touch an installed app.
- `recognize-screenshot-text.swift`: uses the macOS Vision framework for release-preflight OCR of Play listing images; no external OCR package is required.
- `fix-whisper-rn-codegen.js`: post-install compatibility patch for the installed Whisper React Native codegen metadata. Runs automatically after `npm install`.
- `strip-unused-rnfs-disk-api.js`: removes the unused iOS `react-native-fs` disk-capacity export after install so the release binary does not contain an undeclared required-reason API. It fails loudly if the dependency source layout changes and needs a fresh privacy audit.
- `patch-rnfs-android-download-timeouts.js`: keeps configured connection/read timeouts and request headers when `react-native-fs` follows an Android download redirect; range headers are required by the chunked model downloader. It runs during post-install and fails loudly if the audited dependency code changes.
- `check-android-16k.js`: verifies release-APK ZIP alignment and every packaged arm64 ELF `LOAD` segment against Google Play's 16 KB page-size requirement. Run `npm run android:check-16k` after assembling the final release APK; passing an AAB path checks its arm64 ELF segments while preflight separately verifies its bundle alignment configuration; safe for CI when Android SDK 36 and the pinned NDK are available.
- Store screenshots are generated by the guarded Detox journeys in `e2e/store-screenshots.test.js` and `e2e/starter.test.js` through `npm run store:screenshots:ios`, `npm run store:screenshots:ios:ipad`, and `npm run store:screenshots:android`. The Android command captures a ready topic home with the verified Gemma model installed and a topic detail after real synthesis; both require `CONTEXTENGINE_MODEL_PATH` to reference that model. These commands are local/macOS-only because they use Simulator/ADB, Detox, `sips`, and `ffmpeg`.
- `ensure-ios-store-simulator.js`: local/macOS-only idempotent setup used by both iOS screenshot commands; it reuses an available matching simulator or creates the required iPhone 16 Pro Max / 13-inch iPad on the newest installed iOS runtime.

Before adding scripts, document their purpose, required environment, and whether they are safe to run in CI or only intended for local/manual use.
